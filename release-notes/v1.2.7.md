## IronNestFCS Smart v1.2.7

### Loaded-ready gun matching fix / 已装填待机炮匹配修复

- When one Pending task is compatible with both guns, the matcher now prefers a gun that is already `LoadedReady` over an `EmptyReady` gun that would need a fresh load.
- The rule is intentionally limited to the same single-task Left/Right choice. Multi-task matching, maximum-cardinality selection, charge/range resource protection, Pending order, ETA and azimuth tie-breaking are unchanged.
- High-volume normal-level `[FCS Match]` diagnostic probe output is disabled for release; exceptional materialization warnings are retained.

- 当同一个 Pending 任务同时兼容左右两门炮时，如果一门炮已经处于 `LoadedReady`，另一门炮为需要重新装填的 `EmptyReady`，现在会优先使用已经待机的炮。
- 该规则仅作用于“同一单任务的左右炮二选一”，不会改变多任务匹配、最大匹配数、装药/射程资源保护、Pending 顺序、ETA 或方位角的既有优先级。
- 发布版关闭了普通级别的高频 `[FCS Match]` 诊断探针输出；异常的弹道物化失败警告仍保留。

### Validation / 验证

- In-game smoke test passed for the reported `LoadedReady C6 + EmptyReady` single-task case.
- Source-level review confirms that the new preference does not participate in multi-task set selection.

- 已通过 `LoadedReady C6 + EmptyReady` 单任务场景的游戏内简单测试。
- 源码检查确认该优先规则不会参与多任务任务集选择。
