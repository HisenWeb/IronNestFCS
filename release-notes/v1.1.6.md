## IronNestFCS Smart v1.1.6

### Estimated shell flight time / 预计炮弹飞行时间

- The top-left FCS status panel now shows the estimated shell flight time for the current FirePlan after the game has prepared its Time-To-Impact value.
- Smart reads the game's own mechanical Time-To-Impact dial instead of maintaining a separate projectile-speed model.
- The captured value is stored with the current FirePlan, so it stays as the original estimated flight time after firing instead of counting down.

- 左上角 FCS 状态面板现在会在游戏准备好 Time-To-Impact 数据后显示当前 FirePlan 的预计炮弹飞行时间。
- Smart 直接读取游戏自己的机械 Time-To-Impact 表盘，不再维护独立的炮弹速度 / 飞行时间模型。
- 该预计值会保存到当前 FirePlan，因此击发后仍显示原始预计飞行时间，不会跟随游戏倒计时继续减少。

### Automatic UI language / 自动界面语言

- The FCS UI no longer uses `language.txt` or separate Chinese/English packages.
- Smart reads the game's localized left Time-To-Impact label: the exact label `左` selects Simplified Chinese; every other state or language falls back to English.
- The cached game label is checked periodically, allowing the FCS UI to follow an in-game language change without maintaining a separate mod-language setting.

- FCS UI 不再读取 `language.txt`，也不再维护独立的中文包 / 英文包。
- Smart 读取游戏左炮 Time-To-Impact 的本地化标签：严格识别到 `左` 时使用简体中文，其余任何情况统一使用英文兜底。
- 运行时会定期读取已缓存的游戏标签，因此游戏内切换语言时，FCS 可以自动跟随，不需要额外的 Mod 语言配置。

### Universal package / 通用安装包

- Release packaging now produces one archive for all players: `IronNestFCS-Smart_vX.X.X.zip`.
- `language.txt` is no longer included in the archive.
- `tools/Release.ps1` now publishes the universal ZIP together with `SHA256SUMS.txt`.

- 发布流程现在只生成一个所有玩家共用的安装包：`IronNestFCS-Smart_vX.X.X.zip`。
- 安装包中不再包含 `language.txt`。
- `tools/Release.ps1` 现在只发布通用 ZIP 与 `SHA256SUMS.txt`。

### Diagnostic cleanup / 诊断清理

- The temporary trajectory-stopwatch research probe has been removed from the release branch.
- The dedicated `flight.log` diagnostic category and high-frequency trajectory probe output are removed.
- The production `TimeToImpactReader` remains read-only and is used only to populate the FirePlan/HUD value.
- Normal logging behavior is unchanged: compact `problems.log` by default, full categorized diagnostics only when `diagnostics.txt` is set to `on`.

- 开发阶段的轨迹 / 秒表研究探针已经从发布分支移除。
- 删除独立的 `flight.log` 分类和高频轨迹探针日志，避免测试型日志持续膨胀。
- 正式的 `TimeToImpactReader` 仍保留为只读功能，只负责向 FirePlan / HUD 提供预计飞行时间。
- 正常日志策略不变：默认只写精简 `problems.log`，只有将 `diagnostics.txt` 设为 `on` 时才生成完整分类诊断日志。

### Notes / 说明

- This release does not change the core T1–T4 queue, dual-gun scheduling, F9 replanning, or persistent physical-loading semantics.
- Existing `language.txt` files from older installations may be left in place; v1.1.6 no longer reads them.

- 本版本不改变 T1～T4 任务队列、双炮调度、F9 重规划或持久物理装填的核心语义。
- 旧版本安装目录中残留的 `language.txt` 可以保留；v1.1.6 已不会读取它。
