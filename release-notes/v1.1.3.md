## IronNestFCS Smart v1.1.3

### Fixes / 修复

- Fixed the firing-origin calculation used for Tactical Map target distance and azimuth.
- The FCS no longer treats the draggable blue `Player Turret Piece` marker as the authoritative turret position.
- Fire-control calculations now use the game's `TurretLocation` anchor as the real firing origin.
- This fixes target distance and azimuth errors when the blue map marker does not match the turret's actual firing position.

- 修正 Tactical Map 目标距离与方位计算使用的炮位原点。
- 火控系统不再把可拖动的蓝色 `Player Turret Piece` 标记当作真实炮位。
- 火控计算现在使用游戏中的 `TurretLocation` 作为真实射击原点。
- 修复蓝色地图炮位标记与真实炮位不一致时导致的目标距离与方位偏差。

### Internal / 内部改进

- Added and hardened the one-command release workflow.
- Fixed Windows PowerShell handling when the target GitHub Release does not yet exist.
- Fixed ambiguous `master` branch/tag refs in the release workflow.

- 完善一键发布流程。
- 修复 Windows PowerShell 在目标 GitHub Release 尚不存在时提前中止的问题。
- 修复仓库同时存在 `master` 分支与 `master` 标签时的发布引用歧义。
