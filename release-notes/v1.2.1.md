## IronNestFCS Smart v1.2.1

### F8 HUD toggle / F8 HUD 开关

- Press **F8** to hide or show the top-left IronNestFCS Smart status HUD.
- The toggle affects HUD drawing only. Task execution, Pending scheduling, loading, aiming, Auto Fire and other fire-control behavior continue normally while the HUD is hidden.
- HUD visibility is owned by the stable Host, so pressing **F9** to reload/replan the TaskSystem does not reset the current HUD visibility state.
- Starting a new game process returns to the normal visible HUD state.

- 按 **F8** 可以隐藏或重新显示左上角 IronNestFCS Smart 状态 HUD。
- 这个开关只控制 HUD 绘制。HUD 隐藏后，任务执行、Pending 调度、装填、瞄准、Auto Fire 和其他火控行为都会继续正常运行。
- HUD 显示状态由稳定 Host 持有，因此按 **F9** 热重载 / 重新规划 TaskSystem 时不会重置当前 HUD 显示状态。
- 重新启动游戏进程后，HUD 会回到正常显示状态。

### Notes / 说明

- **F8** is a display-only convenience control; it does not clear missions or change the fire-control plan.
- **F9** behavior is otherwise unchanged: it still resets reloadable TaskSystem planning/execution state while preserving already-accepted physical loading work in the stable Host.

- **F8** 只是显示层快捷开关，不会清除任务，也不会改变火控计划。
- **F9** 的其他行为保持不变：仍然只重置可热重载 TaskSystem 的规划 / 执行状态，并保留稳定 Host 已经接受的实际装填工作。
