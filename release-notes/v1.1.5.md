## IronNestFCS Smart v1.1.5

### UI layout / 界面布局

- Reworked the Tactical Map controls to avoid the default tool area on the right side of the table.
- Split the ammunition selector into two columns while keeping the original row spacing.
- Kept `Auto Fire`, `Max Charge`, and `T1–T4` together as a clear control block above the second ammunition column.
- Aligned the lower-right ammunition column with the bottom of the left column for a more balanced layout.

- 重新调整战术地图右侧控件布局，避开桌面右侧工具的默认占用区域。
- 弹种选择改为双列显示，同时保持原有行距。
- `Auto Fire`、`Max Charge` 与 `T1–T4` 继续作为独立控制区，位于右侧弹种列上方。
- 右下弹种列底部与左侧弹种列对齐，使整体布局更均衡。

### Runtime cleanup / 运行时清理

- Host-side shutdown cleanup now runs before Unity tears down scene objects, reducing the chance of stale runtime state during game exit or unload.
- `OnDeinitializeMelon` remains as an idempotent fallback for non-standard unload paths.

- Host 侧清理现在会在 Unity 销毁场景对象之前执行，降低退出游戏或卸载时残留运行状态的可能性。
- `OnDeinitializeMelon` 仍保留为非标准卸载路径的幂等兜底。

### Documentation / 文档

- Updated repository links and upstream attribution after the Smart rename.
- Installation guidance continues to require the complete package structure (`Mods`, `UserLibs`, and `UserData`), not only `IronNestFCS.dll`.

- Smart 重命名后更新了仓库链接与 upstream 来源说明。
- 安装时仍需完整保留安装包中的 `Mods`、`UserLibs` 与 `UserData` 目录结构，不能只安装 `IronNestFCS.dll`。

### Notes / 说明

- This release does not change the core mission-queue, F9 replanning, or dual-gun scheduling semantics introduced in the current Smart architecture.
- Both language packages contain the same binaries; only the default `language.txt` differs.

- 本版本不改变当前 Smart 架构中的任务队列、F9 重规划或双炮调度核心语义。
- 中英文安装包包含相同二进制文件，仅默认的 `language.txt` 不同。
