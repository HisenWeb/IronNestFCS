## IronNestFCS Smart v1.2.3

### Combat HUD cleanup / 战斗 HUD 精简

- The top-left FCS HUD has been reorganized around information that is useful during live fire-control work.
- Active gun rows keep the current T mission, shell type, progress, elapsed time, impact grid, azimuth, charge, elevation and estimated shell flight time.
- Idle gun rows continue to show the gun's current physical ammunition / recovery state.
- Firing-order status plus Auto Fire / Max Charge state remain visible.
- Pending rows now focus on the mission itself: target, shell type, impact grid and azimuth. Gun-compatibility mismatch text is no longer attached to the task row.
- Session success/failure statistics, recent-task history and internal per-gun ETA / alignment diagnostics were removed from the always-on HUD to reduce visual density.
- The existing **F8** HUD show/hide toggle is unchanged.

- 左上角 FCS HUD 重新整理为以实时火控过程中真正需要的信息为主。
- 正在执行任务的炮位继续显示当前 T 任务、弹种、进度、已用时间、打击位置、方位角、装药量、仰角和预计炮弹飞行时间。
- 空闲炮位继续显示当前真实弹药状态或复位 / 恢复状态。
- 射击顺序，以及 Auto Fire / Max Charge 状态继续保留。
- Pending 行现在只描述任务本身：目标、弹种、打击位置和方位角；不再把“弹种不匹配”等炮位兼容性信息挂在任务行上。
- 为降低常驻 HUD 的信息密度，移除了本轮成功 / 失败统计、近期任务历史，以及每门炮内部的 ETA / alignment 调度诊断。
- 现有 **F8** HUD 显示 / 隐藏开关保持不变。

### Notes / 说明

- This is a presentation-only change. Planner, Matcher, Dispatcher, FirePlan execution, loading runtime, ballistic planning, physical-fire settlement, Auto Fire and F9 lifecycle behavior are unchanged.
- Simple in-game smoke testing passed before release preparation.

- 本版本只调整 HUD 信息呈现，不修改 Planner、Matcher、Dispatcher、FirePlan 执行、装填运行时、弹道规划、实际击发结算、Auto Fire 或 F9 生命周期逻辑。
- 发布准备前已完成简单实机测试。
