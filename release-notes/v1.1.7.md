## IronNestFCS Smart v1.1.7

### Earlier estimated shell flight time / 更早显示预计炮弹飞行时间

- Estimated shell flight time is now populated as soon as a FirePlan is created instead of waiting until the gun reaches `WaitingForFire`.
- Smart uses measured in-game C1–C6 charge coefficients with target range to estimate TTI early.
- The existing mechanical Time-To-Impact dial reader remains available as a fallback when an early estimate cannot be produced.
- The HUD behavior is otherwise unchanged: the stored FirePlan value remains the original estimated flight time and does not count down after firing.

- 预计炮弹飞行时间现在会在 FirePlan 创建后立即写入，不再等待火炮进入 `WaitingForFire`。
- Smart 使用游戏内实测得到的 C1～C6 装药档位系数与目标距离提前估算 TTI。
- 原有机械 Time-To-Impact 表盘读取仍作为提前估算不可用时的回退路径。
- HUD 其余行为不变：FirePlan 保存的是原始预计飞行时间，击发后不会跟随机械表盘倒计时继续减少。

### Empirical TTI model / 实测 TTI 模型

Observed game behavior is linear in range for a fixed powder charge:

```text
TTI(seconds) = distance(km) * secondsPerKm(charge)
```

Production coefficients:

```text
C1 = 4.758869 s/km
C2 = 3.830061 s/km
C3 = 2.613011 s/km
C4 = 1.894451 s/km
C5 = 1.540442 s/km
C6 = 1.427168 s/km
```

Across the tested ranges, changing elevation while keeping the same charge did not require a separate TTI correction; the per-charge ratio remained stable within the precision of the game's dial/log values.

游戏实测表现为：固定装药档位下，TTI 与距离近似严格成正比：

```text
TTI(秒) = 距离(km) * 当前装药档位系数
```

正式版本使用上面的 C1～C6 六档实测常量。在已测试距离范围内，同一装药档位改变仰角时不需要额外的 TTI 修正；按游戏表盘与日志精度观察，每档的 `TTI / 距离` 保持稳定。

### Probe cleanup / 测试探针清理

- The production branch does not include the temporary TTI timing probes, dial-sampling probes, or validation-only logging used to derive the coefficients.
- The change is limited to the compact estimator, FirePlan initialization, documentation, and the existing read-only dial fallback.

- 正式分支不包含本轮用于推导系数的 TTI 时序探针、表盘采样探针或仅用于验证的测试日志。
- 正式改动仅保留精简估算器、FirePlan 初始化、相关文档，以及原有只读机械表盘回退。

### Notes / 说明

- This release does not change target selection, T1–T4 queueing, dual-gun scheduling, Max Charge policy, F9 replanning, or persistent physical-loading semantics.
- TTI estimation remains descriptive HUD data; it does not make tactical decisions or alter the firing solution selected by the game's ballistic calculator.

- 本版本不改变目标选择、T1～T4 队列、双炮调度、Max Charge 策略、F9 重规划或持久物理装填语义。
- TTI 估算仍然只是 HUD / FirePlan 描述数据，不参与战术决策，也不修改游戏弹道计算器给出的射击解。
