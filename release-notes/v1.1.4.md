## IronNestFCS Smart v1.1.4

### Logging / 日志

- Detailed diagnostic logging is now opt-in instead of always enabled.
- Normal play writes only the compact `problems.log`, greatly reducing log size and disk writes.
- Set `UserData/IronNestFCS/diagnostics.txt` to `on` and press F9 to restore the full categorized diagnostic logs when troubleshooting.
- Set it back to `off` and press F9 to return to the compact logging mode.

- 详细诊断日志现在改为按需开启，不再默认持续写入。
- 正常游戏只写精简的 `problems.log`，显著减少日志体积和磁盘写入。
- 排查问题时，将 `UserData/IronNestFCS/diagnostics.txt` 改为 `on`，再按 F9，即可恢复完整分类日志。
- 排查结束后改回 `off` 并再次按 F9，即可恢复精简日志模式。

### Documentation / 文档

- Updated the in-game usage guide to distinguish red target markers `1–4` from the `T1–T4` mission submit buttons.
- Added screenshots for target placement and mission submission.
- Documented the top-left FCS status panel and the new diagnostics switch.

- 更新游戏内使用说明，明确区分红色目标标记器 `1–4` 与任务提交按钮 `T1–T4`。
- 增加目标放置和任务提交截图。
- 补充左上角火控状态面板和新的诊断日志开关说明。
